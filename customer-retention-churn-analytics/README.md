# Real-Time Customer Retention & Churn Analytics

Portfolio project combining behavioral analytics, cohort retention, churn modeling, customer segmentation and real-time risk monitoring.

## Business Questions
- Which customers are likely to churn?
- Which cohorts retain best?
- What behaviors precede churn?
- What is customer lifetime value by segment?
- Which customers should receive retention outreach?

## Stack
Python, Pandas, NumPy, scikit-learn, SQL, PostgreSQL, Kafka/Spark concepts, Streamlit.

## Step-by-Step
1. Generate customer activity events.
2. Build customer-level behavioral features.
3. Label churn from inactivity windows.
4. Train and evaluate a baseline logistic-regression model.
5. Rank customers by churn probability and estimated value.
6. Calculate cohort retention and LTV.
7. Display high-risk/high-value customers in the dashboard.

## Portfolio outcome
Shows practical customer analytics, feature engineering, interpretable machine learning and action-oriented business recommendations.
