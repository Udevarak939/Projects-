# Agile Delivery Plan

## Sprint 1 — Discovery & ingestion
- Define business requirements and KPI dictionary.
- Download Olist data.
- Build schema and quality validation.

## Sprint 2 — Data engineering
- Build PySpark transformations.
- Establish Bronze/Silver/Gold conventions.
- Add PostgreSQL local serving path.

## Sprint 3 — Warehouse & analytics
- Build Snowflake dimensional models.
- Add dbt transformations and tests.
- Implement advanced SQL KPI queries.

## Sprint 4 — BI & AI
- Publish Power BI-ready gold tables and DAX measures.
- Build customer segmentation and churn-risk model.
- Add forecasting/anomaly analysis.

## Definition of Done
Code is reproducible, transformations are documented, data-quality tests pass, credentials are externalized, and business outputs are traceable to source data.
